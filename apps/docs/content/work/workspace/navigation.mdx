# Navigation

## Goal

Learn the Business sidebar so you can open the right surface without hunting.

## Prerequisites

- Business workspace open at `/app/[account]`
- Modules enabled for the areas you need (Settings)

## Sidebar map

Business workspaces group links into sections. Labels below match the default **work / Business** profile.

### Work

| Sidebar label | Typical path | Use for |
| --- | --- | --- |
| Dashboard | `/app/[account]` | Workspace home |
| Projects | `/app/[account]/projects` | Delivery jobs and phases |
| Tasks | `/app/[account]/tasks` | Cross-project task list |
| Planner | `/app/[account]/planner/day` | Today / AI day planning |
| Schedule | `/app/[account]/schedule` | Calendar-style schedule |
| Scheduling | `/app/[account]/scheduling` | Public booking pages |

### Clients

| Sidebar label | Typical path | Use for |
| --- | --- | --- |
| Pipeline | `/app/[account]/pipeline` | Deal board |
| Clients | `/app/[account]/clients` | Client records |
| Meetings | `/app/[account]/meetings` | Transcripts & extracted tasks |
| Activity | `/app/[account]/activity` | Desktop activity from Assistant for Mac |
| Emails | `/app/[account]/email` | Email assistant (when available) |
| Websites | `/app/[account]/websites` | Studio / client sites |
| Support | `/app/[account]/support` | Support tickets |

**Shared clients** appears when partners shared clients into this workspace.

### Commercial

| Sidebar label | Typical path | Use for |
| --- | --- | --- |
| Invoices | `/app/[account]/invoices` | Client invoices |
| Proposals | `/app/[account]/proposals` | Sales proposals |
| Contracts | `/app/[account]/contracts` | Contracts |
| Finances | `/app/[account]/finances` | Finances / integrations views |

### Team & tools

| Sidebar label | Typical path | Use for |
| --- | --- | --- |
| Team | `/app/[account]/members` | Members and invites |
| Notes and files | `/app/[account]/notes` | Notes |
| Second brain | `/app/[account]/brain` | Knowledge chat (when enabled) |
| SOPs | `/app/[account]/sops` | Process checklists |
| Messages | `/app/[account]/messages` | Team / client chat |

### Apps

Marketplace apps (Rankly, Signatures, Videos, Generate, and so on) appear when installed or enabled for the workspace.

### Settings

Open **Settings** from the shell footer / settings entry → `/app/[account]/settings`. Common sub-pages:

- **General**, **Focus & Availability**, **Activity tracking**
- **Payments**, **Services**, **Finances**, **Brand**, **Brand voice**, **Templates**
- **Billing** — your Ozer subscription (not client invoices)

## Steps: find something quickly

1. Confirm you’re on the correct workspace in the account switcher.
2. Expand the section that matches the job (Work / Clients / Commercial / Team & tools).
3. Click the sidebar label listed in the tables above.
4. If the item is missing, open **Settings** and check modules, or ask an admin about your role.

## Tips

- Mobile uses a bottom nav / chrome with the same destinations; labels stay consistent.
- Marketing deep-dives: [Features](https://www.ozer.so/features) · [Apps](https://www.ozer.so/apps).
- Keyboard and accessibility preferences live under account settings (personal or workspace, depending on context).

## Troubleshooting

| Problem | What to try |
| --- | --- |
| Empty or short sidebar | Role permissions or modules disabled |
| “Emails” missing | Email assistant add-on / availability for the account |
| Wrong language of board name | Some profiles rename Pipeline (for example WIP in property) — Business uses **Pipeline** |
