# Navigation

The commercial sidebar is ordered for agency desks. Paths use your workspace slug: `/app/[account]/…`.

## Main sidebar

| Label | Path | Use for |
| --- | --- | --- |
| Dashboard | `/app/[account]` | Agency overview and prompts |
| Disposals | `/app/[account]/listings` | Occupational and investment instructions |
| WIP | `/app/[account]/pipeline` | Instruction stages (Potential → Completed) |
| Contacts | `/app/[account]/clients` | Landlords, tenants, investors, solicitors, agents |
| Requirements | `/app/[account]/pipeline?view=requirements` | Acquisition / search requirements board |
| Viewings | `/app/[account]/viewings` | Diary of viewings and feedback |
| HoTs / Proposals | `/app/[account]/proposals` | Heads of terms and proposals |
| Sales register | `/app/[account]/leases` | Completed lettings / sales register |
| Insights | `/app/[account]/commercial-reports` | Disposals, viewings, and requirements metrics |
| Tasks | `/app/[account]/tasks` | Team tasks |
| Notes and files | `/app/[account]/notes` | Shared notes and files |
| Team | `/app/[account]/members` | Members, invites, seats |

The WIP board name can be renamed in settings; the default label is **WIP**.

## Settings group

| Label | Path | Use for |
| --- | --- | --- |
| Workspace settings | `/app/[account]/settings` | Branding, modules, timezone |
| Website & portals | `/app/[account]/commercial-publishing` | Property Hive, Rightmove, EACH / EG |

Website & portals is **not** Site Studio. Commercial publishing connects agency marketing (Property Hive website sync and UK portals). Site Studio belongs to the Business workspace, not this docs set.

## Steps to find your way around

1. Switch to the commercial team workspace.
2. Skim top to bottom: Disposals → WIP → Contacts → Requirements.
3. Open a disposal and note the detail tabs: Overview, Marketing, Media, Interest, Availability, Management.
4. Open **Website & portals** before you go live on portals.
5. Use **Insights** for weekly pipeline health.

Keyboard and accessibility preferences live under account settings.
