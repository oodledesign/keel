# Create your account

## Goal

Sign up so you have an Ozer user and personal hub, then continue into Business workspace setup.

## Prerequisites

- Email address (or a supported OAuth provider)
- Ability to click the verification link if email confirmation is required

## Steps

1. Open [app.ozer.so](https://app.ozer.so) and choose **Sign up** (or go to `/auth/sign-up`).
2. Register with email and password, magic link, or a supported OAuth provider (for example Google).
3. If prompted, confirm your email from the verification message.
4. Complete the short onboarding flow. You’ll start with a **personal** account at `/app`.
5. Continue to create or select a **Business** team workspace when the product asks for workspace type (see [First workspace](/work/getting-started/first-workspace)).

## What you’ll see

- Auth screens for sign-in / sign-up / verify email
- Personal home under `/app` after you authenticate
- Account switcher once you have more than one workspace

## Tips

- Use your primary work email so invites and invoice PDFs look professional.
- If you already have an account, use **Sign in** at `/auth/sign-in` instead of creating a duplicate.

## Troubleshooting

| Problem | What to try |
| --- | --- |
| No verification email | Check spam; request a resend from the verify screen |
| OAuth denied | Allow pop-ups; retry with the same Google account |
| Stuck after signup | Sign out and back in, or email [hello@ozer.so](mailto:hello@ozer.so) |

Need help during onboarding? Use **Support** in the product, or email [hello@ozer.so](mailto:hello@ozer.so).
