# Listing detail

Open any disposal from `/app/[account]/listings` to reach `/app/[account]/listings/[id]`. The left (or top, on mobile) nav groups the work into these tabs:

| Tab | Path suffix | Purpose |
| --- | --- | --- |
| Overview | (base) | Snapshot of status, address, and key metrics |
| Marketing | `/marketing` | Particulars, marketing copy, and public messaging |
| Media | `/media` | Public photos, floorplans, and brochure assets |
| Interest | `/interest` | Interest schedule against contacts / requirements |
| Availability | `/availability` | Units, floors, and availability schedule |
| Management | `/management` | Instruction, assignment, parties, private media, portal publications |

## Overview

1. Open the disposal from Disposals.
2. Confirm address, disposal type, and status badge.
3. Use the summary widgets (for example upcoming viewings) as a jump-off point into other tabs.
4. Switch tabs from the listing nav — do not create a second disposal for the same instruction.

## Marketing

1. Open **Marketing**.
2. Complete headline particulars, description, and any AI-assisted draft fields you use.
3. Align marketing text with the physical **Availability** schedule before going live.
4. Save, then move listing status to **Marketing** only when content and media are ready.

## Media

1. Open **Media**.
2. Upload public images and documents intended for brochures and portals.
3. Set a primary image so list views and feeds look correct.
4. Keep sensitive files (keys, reports, solicitor packs) on **Management → private media**, not here.

## Interest

1. Open **Interest**.
2. Add or attach interest from contacts and requirements.
3. Progress each row through the interest schedule (for example new → viewing arranged → viewed → offer → under offer → agreed).
4. Cross-check with [Viewings](/commercial-property/viewings) so diary and interest stay aligned.
5. When interest becomes a serious negotiation, also update WIP / HoTs as appropriate.

## Availability

1. Open **Availability**.
2. Record total size or break down floor-by-floor / unit-by-unit.
3. Mark units available, under offer, or let/sold so marketing matches stock.
4. Revisit after each letting or sales completion.

## Management

1. Open **Management**.
2. Complete **instruction** fields (terms of engagement, control, sizing accuracy, and related attributes).
3. Assign internal **negotiator / team** ownership.
4. Add **co-agents** when jointly instructed.
5. Attach **landlord** and **other** parties from Contacts.
6. Capture advanced attributes (for example BREEAM) when required for marketing or portals.
7. Upload **private** media that must not publish.
8. Review portal / Property Hive **publication** status for this listing.

You need a billable seat to mutate management fields. Support seats remain view / notes limited — see [Seats & billing](/commercial-property/seats-billing).
