# Tasks

**Tasks** (`/app/tasks`) is the Personal list for to-dos across life and, optionally, every workspace you belong to.

## Open Tasks

1. Select **Tasks** in the Personal sidebar, or go to `/app/tasks`.
2. Choose a workspace filter: **Personal** only, a specific workspace, or **All** when cross-workspace inclusion is on.
3. Scan due dates and priorities, then open a task to edit details or mark it complete.

## Create a task

1. From **Tasks**, use the create control (or the workspace “new” menu on mobile).
2. Give the task a clear title — one outcome per task.
3. Set due date and optional link to a Personal project if it belongs to a larger plan.
4. Save, then optionally drop it into **Planner** (`/app/planner/plan`) for today’s schedule.

## Work across workspaces

1. In Personal preferences, enable including workspace tasks when you want a single inbox of open work.
2. Filter `/app/tasks` by workspace when you need to focus (for example Business delivery only).
3. Complete or reassign from the workspace that owns the work when that is required — Personal is the hub, not a replacement for Business project boards.

## Tips

- Keep Personal tasks for life and solo plans; keep client delivery tasks in Business projects.
- Suggested work from email can feed Tasks via **Personal email** (`/app/email/suggested-tasks`).
- Pair Tasks with the day view at `/app/planner/day` when you only need “what’s on now”.
