# Viewings

Viewings are the diary of property appointments and feedback. Open the list at `/app/[account]/viewings`.

## Viewing statuses

1. **Upcoming** — scheduled in the diary
2. **Completed** — took place
3. **Awaiting feedback** — happened; outcome not yet captured
4. **Cancelled** — did not proceed

## Outcomes (feedback)

After a viewing, capture sentiment:

1. **Positive**
2. **Neutral**
3. **Negative**

## Book a viewing

1. Open `/app/[account]/viewings`.
2. Choose **New viewing** (or the create action).
3. Select the **disposal** (listing) and the **contact(s)** attending.
4. Set date, time, and location / access notes.
5. Save — status starts as **Upcoming**.
6. Optionally add a matching interest row on the disposal **Interest** tab (`viewing arranged`).

## After the viewing

1. Open the viewing record.
2. Mark it **Completed** or move it through **Awaiting feedback** if notes are pending.
3. Record outcome (positive / neutral / negative) and free-text feedback.
4. Update the disposal **Interest** status (for example to **Viewed** or **Offer made**).
5. If interest cools, keep the requirement on **Actively Searching** or **Withdrawn** as appropriate.

## Desk routine

1. Start the day on Viewings filtered to **Upcoming**.
2. Clear **Awaiting feedback** before end of day so Insights stay accurate.
3. Use Insights (`/app/[account]/commercial-reports`) to monitor feedback lag.
4. Cancel politely and mark **Cancelled** rather than deleting — history helps reporting.
