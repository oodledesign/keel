# Projects & tasks

Delivery lives in **Projects** (jobs) with phases and tasks, plus **Tasks** and **Planner** for day-to-day execution.

## Goal

Turn won work into structured delivery and plan what the team actually does today.

## Prerequisites

- Business workspace at `/app/[account]`
- **Projects** / **Tasks** modules enabled under the **Work** sidebar section

## Surfaces

| Sidebar | Path | Purpose |
| --- | --- | --- |
| **Projects** | `/app/[account]/projects` | Jobs, campaigns, kanban overview |
| **Tasks** | `/app/[account]/tasks` | Cross-project task inbox |
| **Planner** | `/app/[account]/planner/day` | Today view and AI day planning |
| **Schedule** | `/app/[account]/schedule` | Schedule board |

## Guides in this section

- [Projects](/work/projects-tasks/projects) — create jobs, phases, portal sharing
- [Tasks & planner](/work/projects-tasks/tasks-planner) — tasks, review, plan for the day

## Suggested flow

1. Create a project linked to a client.
2. Break it into phases and tasks.
3. Plan today’s work in **Planner**.
4. Invoice from **Commercial → Invoices** when milestones complete.
