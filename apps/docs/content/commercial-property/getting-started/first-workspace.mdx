# First workspace

Commercial property data lives on a **team workspace** whose profile is commercial property. The URL slug becomes `[account]` in every path below `/app/[account]/…`.

## Steps

1. Create or open the team workspace you will use for the agency (for example `/app/bracketts`).
2. Confirm the workspace profile is **Commercial property** so the sidebar shows Disposals, WIP, Requirements, Viewings, and related items.
3. Set the **workspace name and branding** so teammates recognise the space.
4. Set **timezone** for viewing schedules and reminders.
5. Open **Team** at `/app/[account]/members` and check you are a billable seat before mutating listings or publishing.
6. Optionally open **Website & portals** at `/app/[account]/commercial-publishing` and leave credentials blank until you are ready.

## What to configure first

| Setting | Why it matters |
| --- | --- |
| Workspace name | Shown to members and in invitations |
| Timezone | Viewings and planner times |
| Billable seats | Negotiators who create and edit disposals |
| Support seats | View-only / notes help without editing stages |
| Portal credentials | Property Hive, Rightmove, EACH / EG when publishing |

You can change modules later under workspace settings. See [Workspace](/commercial-property/workspace) for personal vs team behaviour, and [Seats & billing](/commercial-property/seats-billing) for seat types.
