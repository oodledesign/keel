# Security & trust

Ozer is built for studios that care where their data lives.

## At a glance

- Data residency and security practices are summarised on the marketing **Trust** page
- Access to workspace data is enforced with Postgres **row-level security**
- Billing and auth use established providers (e.g. Stripe, Supabase Auth)

Read the full trust and security overview: [ozer.so/trust](https://www.ozer.so/trust).
